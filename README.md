# FocusFlow Todo App

기깔나는 정적 투두리스트 웹앱입니다.

## 실행 방법

1. 터미널에서 프로젝트 폴더로 이동합니다.
2. 아래 명령을 실행합니다.

```bash
cd c:\myproject\1105
python -m http.server 8000
```

3. 브라우저에서 다음 주소를 열면 됩니다.

```text
http://localhost:8000
```

## 포함 기능

- 할 일 추가
- 우선순위 선택
- 마감일 설정
- 완료/미완료 전환
- 삭제 기능
- 전체/진행 중/완료 필터
- 브라우저 로컬 저장 기능

## 파일 구조

- `index.html` : 메인 구조
- `style.css` : 스타일링
- `script.js` : 동작 로직
